# 九龙下城世界观（修仙 bible）

> 本文件是世界观唯一锚点。所有 NPC 角色卡、prompt、validator、UI 文案均以此为准。
> 调性：**纯修仙**。所有"赛博/义体/芯片/扫描/天道云"已废弃，使用末尾映射表的修仙对应词。

---

## 一、势力立场

四方势力并立，互相忌惮、互相利用，没有真正的"正派"。

### 1. 太清监察院（朝廷耳目）

- **职能**：替天衍朝廷掌"灵根登记"，搜捕未登记的散修，以"妨碍天道"罪名拘押审讯。
- **手段**：望气、登记符、天道镜、暗符卧底。
- **门面**：在九龙下城设外围哨所，全城贴**符箓封咒**，巡逻队两个时辰一过。
- **真实面目**：内部派系林立，专吃灰色案子换政绩。「鹤七」就是其中一名二阶卧底的代号。
- **对玩家**：玩家身上有**非法灵根烙印**，监察院见之必抓。

### 2. 雷罚帮（地下打手）

- **职能**：九龙下城地下三层的实质掌控者，靠"过路费"和"擂台"两条线吃饭。
- **手段**：雷罚锤、立威、断道。
- **底牌**：高层与监察院私下有交易，但底层打手不知道。
- **铁律**：**认令不认境界**——金丹也得交过路费，元婴也得守规矩。敢动手就敢拼命。
- **对玩家**：默认不耐烦，但只要交钱就放行。

### 3. 无相黑市（散修与丹师）

- **职能**：九龙下城最深层的废弃地脉里改的黑市，丹师、符师、信息贩子混居。
- **手段**：丹炉、符箓、走货。
- **铁律**：**等价交换**。亲不认、面子不卖，押金少了不开炉。
- **对玩家**：黑市认灵石不认人。白璃丹炉是其中最硬的招牌。

### 4. 散修

- **职能**：没有门派背景的修士，绝大多数是从乡野挣扎上来的练气期。
- **手段**：低头走路、塞过路费、买黑市丹药勉强突破。
- **铁律**：**先活着，再说话**。
- **对玩家**：玩家本身就是散修，且是"带烙印"的散修——比普通散修更难。

### 关系矩阵

|             | 监察院 | 雷罚帮 | 无相黑市 | 散修 |
|-------------|-------|-------|---------|------|
| **监察院**  | —     | 表面对立，私下勾结 | 视为"灵根隐患"主猎场 | 视为"未登记隐患" |
| **雷罚帮**  | 高层走账，底层骂街 | — | 收过路费，必要时拆铺 | 抽税、立威 |
| **无相黑市**| 提防、避让 | 缴费让路 | — | 接生意，但要押金 |
| **散修**    | 躲 | 怕 | 买药 | 互不来往 |

## 二、境界与社会地位

修仙界以**境界**论身份，但九龙下城的"规矩"比境界更硬。

### 境界阶梯（继承 `cultivationBalance.ts`）

| 境界 | 子阶 | 社会地位 | 待遇 |
|------|------|----------|------|
| 练气期 | 一层~九层 | 蝼蚁 | 路人，过卡口照交灵石，被监察院抓只能认 |
| 筑基期 | 初/中/后期 | 半人 | 可以谈条件、入帮、做掮客 |
| 金丹期 | 初/中/后期 | 老爷 | 黑市开门礼让三分；但**雷罚帮规矩不认丹**，照交 |
| 元婴期 | 初/中/后期 | 权贵 | 在九龙下城是行走的禁忌，监察院见之要请示 |
| 化神期 | （未开放）| 仙人 | 不下九龙下城 |

### 关键裁决（防止 LLM 自由发挥）

- **金丹强者过雷罚帮卡口是否免费？** ❌ 不免。雷罚帮认帮主令不认境界；金丹也得交三十灵石过路费。但敢动手，雷罚帮会请上面来人，玩家承担不起。
- **元婴强者能不能在黑市装大爷？** ❌ 不能。白璃丹炉不卖人情，元婴也得押满灵石。
- **练气一层的玩家能不能和苏鹤平起平坐？** ❌ 不能。苏鹤客气是因为他在记你的名字，不是因为他平等。

## 三、经济与货币

只有一种货币：**灵石**。高纯度灵石叫**灵晶**（兑换比 1:100）。

**绝对禁用现代词**：钱、币、付款、转账、账户、充值、刷卡、银两、铜板。

### 物价定锚（给 NPC 和玩家共同参考）

| 物品 | 灵石价 | 出处 |
|------|--------|------|
| 雷罚帮过路费 | 30 | `quests/pay_thunder_toll` |
| 粗制回气丹 | 10 | `items.cheap_qi_pill` |
| 遮云丹（压低天道镜警戒）| 200 | `items.cloud_veil_pill` |
| 破境丹 | 1500 | `items.breakthrough_pill` |
| 监察密钥（黑市价） | 5000 | `quests/steal_inspector_key` |
| 一条"白璃师父在哪"级别情报 | 500+ | 青姑出价 |
| 一条普通名字情报 | 20 | 青姑出价 |

### 交易铁律

- **押金制**：黑市开炉前押半数灵石，丹废则没收。
- **无赊账**：所有 NPC 拒绝赊账（mock 已写死："滚。"）。
- **等价交换**：可以拿法宝、情报、任务抵灵石，但 NPC 自己估价，不议价。

## 五、地理与场景

九龙下城是一座**自上而下分层**的弃城，原本是上古修仙城，现在被天衍朝廷封禁，只剩底层未净化。

### 分层

```
 ┌──────────────────────────────────┐
 │  上城（监察院总坛、贵族修士）       │ ← 玩家进不去
 ├──────────────────────────────────┤
 │  中城（市集、登记处）              │
 │   └─ 监察院外围（inspector_outpost）│
 ├──────────────────────────────────┤
 │  下城（地下一/二/三层）            │
 │   ├─ 雷罚酒馆（thunder_tavern）   │
 │   ├─ 无相黑市（black_market）     │
 │   └─ 雷罚帮地下三层主营            │
 ├──────────────────────────────────┤
 │  地脉深处（废弃管道、古修遗迹）     │
 │   └─ 玩家洞府（player_cave）      │
 └──────────────────────────────────┘
```

### 场景定位（对应 `server/src/data/scenes.ts`）

| 场景 ID | 中文名 | 层级 | 主要 NPC | 特征 |
|---------|--------|------|----------|------|
| `inspector_outpost` | 监察院外围 | 中城 | 苏鹤 | 全城贴符箓封咒，巡逻队两时辰一过 |
| `thunder_tavern`    | 雷罚酒馆   | 下城 | 赤目、青姑 | 灵酒掺杂讯灵纹，常客是过路费收员与散修 |
| `black_market`      | 无相黑市   | 下城最深 | 白璃 | 古地脉改建，丹炉烟从瓦楞缝里冒 |
| `player_cave`       | 玩家洞府   | 地脉深处 | （无）| 废弃管道挖出来的临时洞府，墙贴自制屏蔽符 |

## 六、时间线与背景事件

按时间倒序排列，给 NPC 共同记忆锚点。

| 时间 | 事件 | 知情者 |
|------|------|--------|
| **半年前** | 天道镜大修，玩家身上的非法灵根烙印短暂失效，玩家借机进九龙下城 | 玩家、白璃（猜到）|
| **一年前** | 监察院在下城设外围哨所，苏鹤以"中立掮客"身份入驻 | 监察院、苏鹤、青姑（猜到）|
| **两年前** | 雷罚帮原帮主暴毙，现任上位后开始大规模收过路费 | 雷罚帮、青姑、白璃 |
| **三年前** | 白璃师父（金丹中期丹师）被太清监察院抓走，丹铺没收，白璃从中州逃到九龙下城 | 白璃、白璃师父的旧识 |
| **远古** | 九龙下城原为上古修仙城，因"灵根浩劫"被天衍朝廷封禁 | 仅典籍记载 |

### NPC 共同记忆锚点（用于 prompt 引用）

- 白璃从不直接谈师父，但抽屉里压着师父牌位。
- 雷罚帮新帮主上位的细节是青姑最贵的情报。
- 苏鹤的代号"鹤七"是青姑次贵的情报。
- 玩家"半年前借天道镜大修进城"这件事，全城没人知道——这是玩家的底牌。

## 七、灵根 + 法宝 + 丹道 体系

### 1. 五行灵根（继承 `cultivationBalance.ts`）

- 五行：金、木、水、火、土。
- 玩家默认灵根分布：金 70 / 木 40 / 水 12 / 火 8 / 土 16——**单灵根偏金**，适合金系功法（`basic_breathing` 九龙吐纳诀就是金主导）。
- 灵根值 ≥ 70 称"主根"，30~70 称"辅根"，< 30 称"杂根"。
- 玩家身上有**非法灵根烙印**——某种被上一辈刻在经脉里的隐秘印记，让监察院的天道镜读不准玩家的灵根波纹。这是玩家能在九龙下城活下来的核心底牌。

### 2. 法宝品阶

| 品阶 | 名称 | 例子 | 准入境界 |
|------|------|------|----------|
| 一阶 | 凡器 | 普通刀剑、丹炉 | 练气期 |
| 二阶 | 灵器 | 焚天令、影骨符 | 筑基期 |
| 三阶 | 法宝 | 灭神针 | 金丹期 |
| 四阶 | 仙器 | （未开放） | 元婴期以上 |

现有三件（对应 `server/src/data/artifacts.ts`）：

- **焚天令**（灵器）：白璃丹炉旧令。玩家曾用它救过白璃一命，装备后白璃语气软三分。
- **灭神针**（法宝）：从监察密钥上拆下的反制构件——本质是一枚刻满**反望气符文**的银针。装备后在监察相关 NPC 面前更敢出声。
- **影骨符**（法宝）：金丹后期才碰得到的尸骨符。装备后玩家的灵压波纹被压平，天道镜读不到。

### 3. 丹道品阶

| 品阶 | 类型 | 例子 |
|------|------|------|
| 一品 | 杂丹 | 粗制回气丹 |
| 三品 | 辅丹 | 遮云丹 |
| 五品 | 突破丹 | 破境丹 |
| 七品+ | 渡劫丹 | （未开放） |

### 4. 修炼与突破

- 修炼通过**吐纳功法**（如九龙吐纳诀）吸纳灵气。
- 突破到下一境界要满足：灵气池满 + 突破成功率检定。**天道警戒（tianDaoAlert）越高，突破失败率越高**——这是设定核心闭环：玩家越张扬，越难突破。
- 突破失败有概率被天道察觉，触发雷罚。
